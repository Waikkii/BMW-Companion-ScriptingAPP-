# BMW MINI Linker · Atelier

基于原有 Scripting 项目的个人使用版车况组件。中号和小号采用 Atelier 极简布局：浅白／深灰跟随系统、车型文字可自定义、位置区域默认留白。

1.0.2 增加极轻的原生渐变，并细化 Apple 系统字体的字重：标题 Semibold、续航数字 Light、辅助信息 Regular。保留 1.0.1 的安全边距、固定行高和数据流程。

## 使用

1. 在 Scripting 中打开本项目。更新现有项目时保留原脚本名称与 `script.json` 配置，以继续使用已有设置与会话。
2. 首次使用在“设置 → 连接与会话管理”中连接 BMW，按 App 内提示完成短信或密码登录。
3. “设置 → 组件外观”可以修改车型标题、预留文字，并选择跟随系统／浅白／深灰。默认标题为通用的 `My BMW`。
4. 在主屏幕添加 Scripting 中号或小号组件并选择此脚本。

正常状态只保留续航、油量／电量、总里程和简短门窗状态。组件不展示位置、地图或车牌；原 App 的连接、车况详情和胎压功能保留。大号沿用精简信息板。

## Scriptable 版本

Scriptable 源码与独立单文件放在单独的 [BMW_scriptable 仓库](https://github.com/Waikkii/BMW_scriptable)，不混入本项目。

## 说明

- 车辆图在设备上通过有效会话与 VIN 从官方接口获取。本仓库不包含车型照片、个人截图或已登录数据。
- 车况时间使用 BMW 后台返回的时间。离线时保留最近数据，并显示离线／登录状态；iOS 决定实际组件刷新时机。
- 登录沿用原项目的第三方 nonce 服务，当前配置见 `compat-config.ts`；连接前需阅读并同意 App 内的说明。
- 1.0.1 布局包含固定标题／数据行、保守的列宽与安全边距，避免窄尺寸组件撑开。
